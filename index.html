사용 방법 — 펼쳐보기
  • 일반 계산: 시작일과 종료일 사이의 월별 일할계산을 수행합니다
  • 이직확인서: 체크박스를 선택하면 종료일(마지막 근로일) 기준 3개월 급여를 자동 계산합니다
  • 자동 월 구분: 각 달의 총 일수(28/29/30/31일)가 자동으로 반영됩니다
  • 3개월 계산: 마지막 근로일로부터 정확히 3개월 전부터 계산합니다 (예: 10/17 → 7/18~10/17)
  • 연도별 최저시급: 근무시간 산정 시 시작일(이직확인서는 종료일)이 속한 연도의 최저시급이 자동 적용됩니다 (2025년 10,030원 · 2026년 10,320원 · 2027년 10,700원)
  • 근속 3개월 미만 이직확인서: 권고사직·폐업 등으로 3개월을 채우지 못하고 이직한 경우 '3개월 미만 근무'를 선택하면 입사일 ~ 마지막 근로일 전체 기간 급여로 산정합니다 (평균임금 산정 시 취업 후 3개월 미만인 경우 준용 · 근로기준법 제2조 제1항 제6호). 실업급여 수급에 필요한 피보험단위기간 180일은 이전 사업장 기간과 합산해 확인하세요
  • 글자 크기: 상단에서 소·중·대를 고르면 사용하는 브라우저에 각자 저장됩니다
  • 4대보험: 월 급여를 입력하면 2026년·2027년 근로자 부담 예상액이 바로 표시됩니다
